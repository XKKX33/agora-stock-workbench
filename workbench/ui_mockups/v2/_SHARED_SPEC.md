# 量化工作台 v2 · 共享设计规范（所有页面必须严格遵守）

本文件是 6 个页面的唯一视觉/结构真相来源。任何页面都必须先读本文件再动手。
目标：6 个独立 HTML 文件打开后必须看起来像**同一个产品的不同页面**，而不是 6 个不同的设计。

## 0. 硬约束（违反即失败）

- 单文件、完全自包含。**禁止任何外部请求**：无 CDN、无 webfont、无 `<script src>`、无外部图片。
  （SVG 的 `xmlns="http://www.w3.org/2000/svg"` 是命名空间声明，允许。）
- 允许内联 `<script>` 写少量交互（Tab 切换、抽屉开关），但页面在 JS 被禁用时仍须可读。
- 全中文 UI。
- **A股习惯：涨=红、跌=绿。严禁使用欧美的绿涨红跌。**
- 目标 1440px 桌面宽度；1024px 优雅退化。移动端不做。
- 必须 `@media (prefers-reduced-motion: reduce)` 关闭所有动效。
- 语义化 HTML；所有交互元素可键盘聚焦且有可见 `:focus-visible` 描边；正文对比度 ≥ 4.5:1。
- 每页右下角固定角标：`工作台 v2 · <页名>`。

## 1. 设计令牌（原样复制到每个文件的 :root）

```css
:root{
  --canvas:#0c0c0d;       /* 页面底 */
  --tile:#161617;         /* 砖块 */
  --tile-2:#1c1c1e;       /* 砖块内嵌层 */
  --sunk:#101011;         /* 下沉区（表格头、代码块） */
  --line:rgba(255,255,255,.08);
  --line-2:rgba(255,255,255,.14);
  --fg:#f4f4f5; --mut:#a1a1aa; --dim:#71717a;

  --violet:#8b5cf6;   /* 主色 / AI / 当前态 */
  --cyan:#22d3ee;     /* 数据 / 因子 */
  --lime:#a3e635;     /* 模型 / ML */
  --amber:#fbbf24;    /* 告警 / 分歧 / 待接入 */
  --up:#f43f5e;       /* 涨（红） */
  --down:#10b981;     /* 跌（绿） */

  --r:24px;           /* 砖块圆角，签名特征，不得低于 20px */
  --r-sm:12px; --gap:16px;
  --mono:ui-monospace,"SF Mono","Cascadia Mono",Consolas,"DejaVu Sans Mono",monospace;
  --sans:system-ui,-apple-system,"Segoe UI","Microsoft YaHei",sans-serif;
}
```

- 砖块：`background:var(--tile); border:1px solid var(--line); border-radius:var(--r); padding:24px; overflow:hidden;`
- **静止无阴影**，仅 hover：`transform:scale(1.006)` + `box-shadow:0 20px 50px -24px rgba(0,0,0,.85)`，200ms ease-out。不得自动播放动画。
- 页面底加氛围：`radial-gradient(1100px 600px at 18% -8%, rgba(139,92,246,.08), transparent 62%)` +
  `radial-gradient(800px 500px at 95% 4%, rgba(34,211,238,.06), transparent 60%)`，
  以及一层 `feTurbulence` 内联 SVG 颗粒（`opacity:.025`，`pointer-events:none`，`position:fixed`，铺满）。
- 所有数字用 `--mono` + `font-variant-numeric:tabular-nums`。
- 微标签：11px、`text-transform:uppercase`、`letter-spacing:.09em`、`color:var(--dim)`。
- 尺度对比要真实存在：hero 数字 clamp 到 48–64px；砖块标题 13px；数据 12–13px。
- 间距节奏不得均匀：砖块间 16px、砖内分组间 20px、行间 8px。

## 4. 数据诚实度标注（强制，这是产品的核心价值之一）

页面上每一处数字必须归入以下三档之一，并有可见的视觉区分（角标/底纹/脚注）：

- **真实**：来自 DuckDB / Tushare 已入库。上文第 3 节的值全部属于此档。
- **结构示例**：为撑满版面而编造的合理数值。必须在所在砖块内标注 `结构示例`（`--dim` 小字或斜纹底）。
- **待接入**：功能已设计但数据源尚未接通。必须用 `--amber` 标注 `待接入` 并写明缺什么。

绝不允许出现无标注的编造数字。绝不允许把"尚未训练的模型"画成"已训练"。

## 6. 反模板要求

必须同时具备至少四项：真实的尺度对比、非均匀的间距节奏、通过层叠/悬停产生的深度、
有性格的排版配对、语义化（而非装饰性）用色、精心设计的 hover/focus/active 态、
打破网格的编排、颗粒/氛围质感、澄清流程的动效、把数据可视化当设计系统的一部分。

**严禁**：默认卡片网格无层级、统一圆角统一阴影统一间距、灰底白卡加一个装饰色、
把库默认样式当成品、Tailwind/shadcn/Bootstrap 模板感。
