01

暗色终端风

QuantDeck / Terminal Portfolio / Midnight Terminal

近黑底、发丝线分隔、等宽表格数字列列对齐，电光青只留给激活态。机构盯盘工位的感觉。

  • 信息密度最高，一屏看完名单＋归因＋复盘
  • 34px 紧凑行高，11–13px 数据字号
  • 最重要的那个数字才有发光

02

Bento 网格风

Bento Grid 配方 · 4 列 / 200px 行 / radius 24px

大小方块拼贴，尺寸本身编码优先级。只有一个 2×2 hero 格子作为视觉锚点。

  • 头号候选独占大格，综合分做巨型数字
  • 格子与 widget 一一对应，扩展新面板最省事
  • 静止无阴影，只在 hover 抬起

打开样张 →
03

亮色 Fintech 卡片风

Linear / Stripe 克制路线

浅底白卡、1px 发丝边框、大留白，靛蓝单一强调色只用在语义处。白天看最不累。

  • 左侧六页导航（数据／因子／选股／回测／模型／绩效）
  • 非均匀间距节奏，靠层叠而非重阴影做深度
  • x/4 类指标做成分段 pip，不写纯文字

打开样张 →
04

数据编辑器风

Notion / Retool · 表格是主角

承认这个系统的真实对象就是台账：每次选股是一行，随时间累积 T+N 收益。所以做成表格工具，不是卡片仪表盘。

  • 吸顶表头＋吸左排名/代码列，行内展开因子归因
  • 单元格内嵌 sparkline／填充条／资金 chip／pip
  • 零 JS 也能展开（纯 CSS 交互）
