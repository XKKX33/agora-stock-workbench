# AGORA 量化工作台 · UI 设计参考规范

## 结论先行

- 整体走「深色底 + 青色科技感」：页面底 `#0b0e14`、主强调色 `#38bdf8`、涨红 `#f0544f`、跌绿 `#26a69a`，数字一律等宽字体，A股习惯（涨红跌绿）是硬约束。
- 布局抄「三栏终端」：左侧 224px 导航 + 中间主内容 12 列栅格 + 右侧 380px 详情抽屉；图表交互抄 TradingView（十字光标、多指标副图、深浅切换），信息密度抄富途/同花顺，卡片质感抄 Linear/Stripe。
- K线直接采用 `tradingview/lightweight-charts`（GitHub 事实标准，性能好、交互齐），主图:成交量:MACD = 3:1:1；全文所有色值、字号、间距、动效时长均已数值化，前端可照着抄。

## 1. 参考对象调研

### 1.1 TradingView（图表交互标杆）
可借鉴：K线交互的「标准答案」——十字光标跟随并展示 OHLC（开高低收）、多指标副图自由叠加、时间轴缩放平移流畅、深浅色主题一键切换。深浅切换应做成全局主题开关而非页面级设置，切主题时图表颜色同步换，动画 150ms 淡入淡出。图表右上角的指标图例（均线色点 + 当前值）和左上角的大字号现价是最值得抄的两个细节。

### 1.2 富途牛牛 / 老虎证券（行情 App 信息密度）
可借鉴：一屏内同时容纳「自选列表 + 分时/K线 + 盘口五档 + 资金流」，每行只给关键字段（现价、涨跌幅、成交额），数字右对齐、等宽、同列小数点对齐，扫一眼就能比大小。涨跌幅用底色标签（红底白字/绿底白字）而不是纯文字染色；自选列表支持拖拽排序和「加自选」星标，行 hover 高亮但保持行高不变，避免抖动。

### 1.3 同花顺 / 东方财富（A股习惯）
可借鉴：涨红跌绿、红涨用 `#f0544f` 一类正红、跌绿用 `#26a69a` 一类青绿，绝不用欧美绿涨红跌。F10 式的「个股档案」信息结构（公司概况/财务/股东/研报）适合拆成抽屉里的分组标签页。自选股分组（自选/持仓/观察池）放在侧栏顶部，切组不刷新页面只换列表内容。

### 1.4 雪球（社区 + 行情融合）
可借鉴：内容卡片式信息流——一条帖子配「标的 + 行情快照 + 用户观点 + 正/负/中性情绪标签」，适合舆情页直接套用。雪球的卡片留白克制、头像和标签圆角统一、卡片间距 12px 而不是堆满整屏。关注按钮、加自选按钮这类高频操作用小号实心按钮，一眼可点。

### 1.5 现代 SaaS Dashboard（Linear / Vercel / Stripe）
可借鉴：暗色科技感的核心是「低饱和底 + 一个高饱和强调色 + 大量留白」，而不是五颜六色。Linear 的卡片 hover 只做 1px 上浮和边框提亮；Vercel 的暗色页面用径向渐变打氛围光、用细边框而非重阴影分层；Stripe 的仪表盘把大数字（营收）放大到 32–40px 并配微标签（11px 大写字母），尺度对比明显。玻璃拟态只用在顶栏、抽屉这类「浮层」，正文面板不用。

### 1.6 开源量化平台（QuantConnect / Backtrader / vnpy / 聚宽）
可借鉴：QuantConnect 的「策略 IDE + 回测结果 + 持仓」三段式布局适合分析页；vnpy 桌面端的深色终端风（黑色底、荧光绿/青色数字）适合做「终端的仪式感」；聚宽的研究页面把「选股条件列表 + 结果表格 + 回测曲线」纵向排列，逻辑顺序清楚。共同教训：量化前端最容易犯的错是每块面板都想要颜色，结果整屏像霓虹灯——正确做法是只有「涨跌、状态、强调」三类颜色被允许出现。

### 1.7 Bloomberg Terminal（补充）
可借鉴：信息密度天花板——深色底、荧光色、网格线极淡，所有功能靠键盘可触达。不必全抄（全抄会吓跑普通用户），但「重要数字大、辅助文字小、无用装饰为零」的原则可以直接用。

## 3. 设计令牌总览（CSS 变量，直接复制到 `:root`）

```css
:root {
  /* 底色与面板 */
  --bg: #0b0e14;              /* 页面底：蓝黑，不是纯黑 */
  --bg-elev: #10141d;         /* 顶栏/抽屉玻璃层下的底 */
  --panel: #121823;           /* 卡片 */
  --panel-2: #171f2d;         /* 卡片内嵌层（表头、输入框内） */
  --sunk: #0d1119;            /* 下沉区：表格头、代码块、图表底色 */
  --line: rgba(148, 163, 184, .14);   /* 常规边框 */
  --line-strong: rgba(148, 163, 184, .24); /* hover/激活边框 */

  /* 强调色：青色系 */
  --accent: #38bdf8;
  --accent-strong: #0ea5e9;
  --accent-soft: rgba(56, 189, 248, .12);

  /* 涨跌色：A股习惯 */
  --up: #f0544f;              /* 涨（红） */
  --up-strong: #e5484d;
  --up-soft: rgba(240, 84, 79, .12);
  --down: #26a69a;            /* 跌（绿） */
  --down-strong: #1e8f85;
  --down-soft: rgba(38, 166, 154, .12);
  --flat: #94a3b8;            /* 平/停牌 */

  /* 中性灰（文字） */
  --fg: #e2e8f0;              /* 主文字 */
  --mut: #94a3b8;             /* 次级文字 */
  --dim: #64748b;             /* 弱文字：仅用于标签/时间戳 */

  /* 语义色 */
  --ok: #34d399;              /* 成功/已连接/可用 */
  --warn: #fbbf24;            /* 警告/采集中/待接入 */
  --danger: #f87171;          /* 错误/失败 */
  --info: #60a5fa;            /* 信息 */
  --ai: #a78bfa;              /* AI 相关（复盘/模型） */

  /* 形状与间距 */
  --r-lg: 14px;               /* 卡片 */
  --r-md: 8px;                /* 按钮/输入框 */
  --r-sm: 6px;                /* 标签/徽章 */
  --gap: 16px;                /* 面板间距 */
  --pad: 20px;                /* 面板内边距 */

  /* 字体 */
  --sans: system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif;
  --mono: ui-monospace, "SF Mono", "Cascadia Mono", Consolas, "JetBrains Mono", monospace;

  /* 动效 */
  --ease-out: cubic-bezier(.22, 1, .36, 1);
  --t-fast: 120ms;
  --t-base: 180ms;
  --t-slow: 250ms;
}
```

关键约定：**静止状态无阴影**（只有 hover 才出现阴影）；圆角不超过 14px（卡片）和 8px（控件），太圆会像玩具；所有数字元素必须 `font-variant-numeric: tabular-nums`。

## 4. 配色系统

- **底色**：页面 `#0b0e14`（带一点蓝的黑），卡片 `#121823`，卡片内层 `#171f2d`。层次靠「亮度差 + 1px 边框」表达，不靠投影。
- **氛围光**：页面底放两个径向渐变，`radial-gradient(900px 500px at 15% -10%, rgba(56,189,248,.07), transparent 60%)` 和 `radial-gradient(700px 400px at 90% 0%, rgba(167,139,250,.05), transparent 55%)`，`position: fixed`、`pointer-events: none`。光要淡，否则廉价。
- **主强调 `#38bdf8`**：用于主按钮、链接、focus 描边、当前导航项、图表 MA10 和 DIF 线。hover 用 `#7dd3fc`（提亮），按压用 `#0ea5e9`。按钮文字用深色 `#062a3a`，青底深字对比更高、更「科技」。
- **涨跌**：涨 `#f0544f`、跌 `#26a69a`。行情数值**只染数字、不染整行**；涨跌幅胶囊用 `--up-soft`/`--down-soft` 打底 + 同色文字。停牌/平用 `--flat`。所有涨跌数据前必须加 `▲`/`▼` 符号（不依赖颜色传达信息）。
- **语义色**：成功/已连接 `#34d399`，警告/采集中 `#fbbf24`，错误 `#f87171`，信息 `#60a5fa`，AI `#a78bfa`。语义色使用面积不得超过强调色，否则整屏变彩灯。
- **禁用配色**：不用纯白做底色、不用霓虹渐变（紫→粉→蓝大渐变）、不用灰色做涨跌（A股无灰色涨跌）。

## 5. 字体层级

- **数字**：一律 `--mono` + `tabular-nums`，K线现价、列表行情、指标值全部右对齐，小数点后位数同列一致（价格 2 位、涨跌幅 2 位带正负号）。
- 字号阶梯：

| 用途 | 字号/字重 | 行高 | 说明 |
| --- | --- | --- | --- |
| 页面标题 | 20px / 600 | 1.3 | 侧栏内容区顶部 |
| 卡片大数字（现价、收益） | 32px / 600（mono） | 1.2 | 数字越大越好，配 11px 微标签 |
| 区块标题 | 14px / 600 | 1.4 | 卡片左上角 |
| 正文/按钮 | 13px / 400 | 1.6 | 默认字号 |
| 表格/行情数据 | 12px / 400（mono 数字） | 1.4 | 列表主体 |
| 微标签/时间戳 | 11px / 500 | 1.4 | `letter-spacing: .08em`，大写英文、中文不强制大写 |
| 辅助说明 | 11px / 400 | 1.5 | 仅限非关键信息，对比度不足时用 `--mut` 不用 `--dim` |

- 大数字（≥24px）加 `letter-spacing: -0.02em`，观感更专业；正文不加负字距。

## 6. 布局规范

- **基准宽度 1440px**，最小可用 1280px，1024px 时右侧抽屉改为覆盖层。移动端不做。
- **三栏壳层**：左侧导航 224px（可折叠到 64px，折叠后只留图标 + tooltip）｜顶栏 56px｜主内容区 padding 24px｜右侧详情抽屉 380px（默认收起，点击标的后滑出）。
- **顶栏**：玻璃拟态（`backdrop-filter: blur(12px)`，背景 `rgba(11,14,20,.78)`，底部 1px `--line`）。左：产品名 + 面包屑；中：当前交易日选择器 + 策略名；右：数据新鲜度状态点 + 「非交易信号」徽章 + AI 开关。顶栏固定，内容滚动不带动顶栏。
- **主内容栅格**：12 列，`gap: 16px`。K线页：左 8 列图表区 + 右 4 列「个股详情 + 指标 + AI 摘要」；列表页：左侧 5 列股票列表 + 右侧 7 列图表联动；舆情页：单列信息流，卡片 12px 间距。
- **间距节奏（不要均匀）**：面板间 16px，面板内分组间 20px，行与行 8px；卡片内边距统一 20px。
- **信息密度**：表格行高 36px、列表行 40px（带自选星标和标签时 44px）；一屏（顶栏以下 ~700px）股票列表至少显示 15 行；K线区总高 640px（主图 384px + 成交量 128px + MACD 128px）。

## 7. 组件规范

- **卡片**：`background: var(--panel); border: 1px solid var(--line); border-radius: var(--r-lg); padding: var(--pad)`。静止无阴影；hover：`transform: translateY(-1px); border-color: var(--line-strong)` + `box-shadow: 0 12px 32px -12px rgba(0,0,0,.5)`，180ms `--ease-out`。顶部可加一条 1px 高光线 `linear-gradient(180deg, rgba(255,255,255,.06), transparent)` 增强「玻璃边缘」感。
- **按钮**：高 32px，圆角 `--r-md`，字号 13px。主按钮：`background: linear-gradient(135deg, #38bdf8, #0ea5e9); color: #062a3a`，hover 提亮 8%（`filter: brightness(1.08)`），按下 `scale(.98)`；hover 时可加 `box-shadow: 0 0 20px rgba(56,189,248,.25)` 光效。次按钮：透明底 + `--line` 边框，hover 背景 `rgba(255,255,255,.04)`。危险按钮：`--danger` 文字 + `--danger` 12% 透明底。禁用：`opacity: .45`，无 hover 效果。按钮内 loading 用 12px 旋转圆环，不换文字宽度（文字固定为「采集中…」占位）。
- **输入框/下拉**：高 32px，圆角 `--r-md`，背景 `--sunk`，1px `--line` 边框，内边距 0 10px，字号 13px。focus：边框 `--accent` + `box-shadow: 0 0 0 3px rgba(56,189,248,.15)`（ring 效果），120ms。
- **表格**：表头 11px / 500、大写、`letter-spacing: .06em`、`--dim` 色、背景 `--sunk`；行高 36px，行分隔线 `rgba(148,163,184,.07)`；行 hover 背景 `rgba(56,189,248,.04)`，行高不变；数字列右对齐 + mono；涨跌幅列用胶囊标签。表头吸顶 `position: sticky; top: 0`。
- **标签/徽章**：高 20px，内边距 0 8px，圆角 `--r-sm`，字号 11px；底色用语义色 12% 透明 + 同色文字；带状态点（6px 圆点）时点在前、文字间距 6px。
- **Tooltip**：背景 `rgba(11,14,20,.95)` + `backdrop-filter: blur(8px)`，1px `--line` 边框，圆角 `--r-md`，内边距 8px 10px，字号 11–12px，阴影 `0 8px 24px rgba(0,0,0,.5)`，出现 120ms 淡入（位移 2px，不跟手跳动）。
- **滚动条**：宽 8px，轨道透明，滑块 `rgba(148,163,184,.25)` 圆角 4px，hover `.35`。
- **focus-visible**：所有可交互元素 `outline: 2px solid var(--accent); outline-offset: 2px`，圆角随元素。
- **空态**：列表无数据时给居中图标 + 一句白话（如「暂无自选股，点右侧星标添加」），不要空白一片。

## 8. 图表规范

- **库**：`tradingview/lightweight-charts`。若项目已用 ECharts，配色和副图比例按本节执行，交互补十字光标。
- **K线蜡烛**：涨 `#f0544f`、跌 `#26a69a`，边框同色（不要黑色描边）；最新一根若未收盘用半透明（`opacity: .75`）。线型：分时图用 1px 实线 `#38bdf8`，面积图渐变 `rgba(56,189,248,.35) → transparent`。
- **均线**：MA5 `#fbbf24`、MA10 `#38bdf8`、MA20 `#a78bfa`、MA60 `#34d399`，线宽 1.5px。图例（左上角）：色点 + `MA5 12.34`，11px mono，与图表同色。
- **副图比例**：主图:成交量:MACD = **3:1:1**（总高 640px 时：384 / 128 / 128）。成交量柱：涨红跌绿、透明度 .55；MACD：DIF `#38bdf8`、DEA `#fbbf24`，柱状图红绿（涨红跌绿，按 MACD 柱正负染色，`.7` 透明度）。
- **十字光标**：跟随鼠标，横竖线 1px `rgba(148,163,184,.4)` 实线；OHLC 数值显示在顶部跟随的深色标签条（背景 `--sunk`、11px mono），当前价格在右侧价格轴显示 12px mono 红色/绿色标签。
- **dataZoom / 时间轴**：底部时间轴保留 lightweight-charts 原生缩放平移（滚轮缩放、拖拽平移）；另加时间范围 chips：分时 / 日K / 周K / 月K / 1年 / 全部，选中态用 `--accent-soft` 底 + `--accent` 文字。若用 ECharts：`dataZoom: [{ type: 'inside' }, { type: 'slider', height: 22, bottom: 8 }]`，滑块配色同强调色。
- **网格**：`rgba(148,163,184,.06)` 水平线，竖线隐藏或同样 0.06；坐标轴文字 11px `--dim`。
- **Tooltip 内容**（十字光标跟随，或悬停显示）：时间（`2026-07-30 14:30`）｜开 高 低 收（红绿染色）｜涨跌额 + 涨跌幅（胶囊）｜成交量 / 成交额；每行 11px mono，键左值右，键 `--dim` 值 `--fg`。
- **深浅色切换**：全局主题开关同时换图表 `chart.applyOptions({ layout: { background: ... } })`，150ms 过渡；本规范先做暗色，浅色只要求可读、色值语义不变。
- **指标面板**：主图下方指标区与主图共享时间轴（lightweight-charts 多 pane 同步），切换指标只换副图 pane 不重建图表。

## 9. 动效规范

- **该动**（总原则：只动「状态变化」，不自动循环）：
  - 面板出现/抽屉滑出：`opacity 0→1 + translateY(8px→0)`，160ms `--ease-out`；
  - 数值刷新闪光：行情数字变化时底色闪一下再消失，涨 `rgba(240,84,79,.16)`、跌 `rgba(38,166,154,.16)`，400ms 渐隐（一次性，不循环）；
  - 按钮 hover/active、输入框 focus：120–180ms，见组件节；
  - Tab/页面切换：内容区 120ms 淡入（不做整页位移，避免眩晕）；
  - 采集/连接进行中：状态点 2s 呼吸脉冲（`scale 1→1.5 + opacity .6→0`），仅此一种允许循环动画；
  - 十字光标：直接跟随，无动画。
- **不该动**：常驻旋转/扫光、自动轮播、K线自动滚动、整页转场位移、hover 放大卡片内容、任何超过 250ms 的动画。
- **数值刷新频率**：行情列表 1–3s 一次全量刷新即可；涨跌变动的行可加 120ms 背景高亮提示。
- **`prefers-reduced-motion: reduce`**：所有动画归零，数值刷新闪光改为静态 0.15 透明度底色 1.5s 后移除，采集状态点只显示实心不呼吸。

## 10. 舆情 / AI 页特殊设计

- **数据源三态**（页面顶部一个总状态徽章 + 每个数据源卡片各自一个状态）：

| 状态 | 视觉 | 交互 |
| --- | --- | --- |
| 未接入 | 卡片虚线边框（`border-style: dashed`），灰点 + 「未接入」，内容区显示空态占位 | 主按钮「接入数据源」，点击后进入采集中 |
| 采集中 | 琥珀色（`--warn`）呼吸点 + 「采集中」，卡片顶部细进度条（`--warn`，宽度按步骤推进） | 按钮禁用显示「采集中…」+ 12px spinner |
| 可用 | 绿色实心点 + 「可用 · 更新于 14:32」 | 主按钮变次按钮「重新采集」，可随时手动刷新 |

- **一键采集反馈闭环**（必须走完，不能只转圈）：点击 → 按钮变 loading → 卡片内出现步骤条「发现源 → 抓取 → 清洗 → 入库」（每步完成打勾，当前步高亮）→ 完成后右上角 toast「采集完成，共 1,286 条，耗时 12s」3s 自动消失（`role="status"` 供读屏）→ 顶部时间戳与新鲜度更新。失败则 toast 变红色（`--danger`）「采集失败：超时」，卡片进入错误态并提供「重试」按钮，不静默失败。
- **数据新鲜度**：顶栏和舆情页都显示「更新于 14:32:05 · 5 分钟前」；超过 30 分钟未更新，点变 `--warn` 并提示「数据可能过期」。
- **舆情内容卡片**（借鉴雪球）：标的 + 来源（东财股吧/雪球/新闻/微博）+ 发布时间 + 摘要 2 行截断 + 情绪标签。情绪用 A股直觉色：正面 `--up`（红）、负面 `--down`（绿）、中性 `--flat`；标签 = 情绪色 12% 底 + 同色文字。卡片间 12px，信息流按时间倒序，顶部提供「全部 / 正面 / 负面 / 中性」筛选 chips。
- **AI 复盘页**：左侧结论卡片（AI 图标 `--ai` 色 + 结论正文 14px）+ 右侧数据证据（K线缩略图、指标表、舆情情绪分布）。AI 输出用打字机效果逐字显示（中文 25–40ms/字，上限 5000 字；`prefers-reduced-motion` 时一次性全量显示）；「生成中」状态用顶部细进度条 + 禁止重复点击，完成后状态点变绿。
- **AI 徽章**：AI 相关按钮/标签统一 `--ai` 色，与数据（青）、涨跌（红绿）区分，防止用户把 AI 输出误当行情。

## 11. 可访问性

- **对比度**：正文 `#e2e8f0` on `#0b0e14` ≈ 13.9:1，次级 `#94a3b8` ≈ 7:1，均达标；`--dim #64748b` ≈ 4.6:1，只用于非关键辅助文字。涨 `#f0544f` ≈ 4.9:1、跌 `#26a69a` ≈ 5.4:1、强调 `#38bdf8` ≈ 7:1，达标。**禁止**在深色底上用 `#f87171` 做正文、禁止用纯灰区分涨跌。
- **不靠颜色传信息**：涨跌必须带 `▲/▼`，状态必须带文字（「采集中」不能只有一个呼吸点），情绪标签必须带文字。
- **键盘**：全站 tab 顺序从左到右、从上到下；卡片可聚焦（表格行、舆情卡片都是可聚焦元素）；`focus-visible` 描边 2px 青色。
- **动效**：全局 `@media (prefers-reduced-motion: reduce)` 关闭所有动画（见第 9 节）。
- **读屏**：采集完成 toast 用 `role="status"`，进度条用 `role="progressbar"` + `aria-valuenow`，图表区提供表格化数据摘要（`aria-label` + 屏幕外表格）。
- **文字最小 12px**（微标签 11px 例外但对比度 ≥ 4.5:1）；按钮可点击区域 ≥ 32×32px。
