# 规格：一键全流程与按日期实验追踪

status: archived
日期: 2026-08-04

权威设计见 `docs/superpowers/specs/2026-08-04-one-click-experiment-tracking-design.md`。

## 固定流程

配置预检 → 更新交易日历 → 更新行情/基础指标/资金流/涨跌停价 → 回填历史收益 → 完整性闸门 → 规则扫描与舆情 → `grok-4.5` 多 Agent → 四组结果事务落库。

## 固定实验组

- `rule`：规则分前 N。
- `ai`：AI 风控最终分前 N。
- `hybrid`：规则分与 AI 分当日百分位各 50%。
- `benchmark`：冻结候选池等权。

## 固定收益口径

信号日为 T，T 后第一个交易日开盘买入。`ret1/ret3/ret5/ret10` 均相对同一买入价；对应目标日收盘价不可得时保持空值并记录原因。

## 固定界面口径

- 全站明亮/暗夜双主题共用一套结构，首次跟随系统、手动选择持久化。
- 明亮主题借鉴 Gemini 的中性留白和低阴影控件，不复制品牌元素；暗夜主题使用中性炭黑并移除蓝紫渐变。
- 系统规则扫描、一键全流程、Agent 选股研判、单股深度研判四个动作不可混名。
- 情绪页 Bug 必须先稳定复现和定位根因，再以回归测试锁定修复。
