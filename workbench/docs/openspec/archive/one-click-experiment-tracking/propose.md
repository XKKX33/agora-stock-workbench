# 一键全流程与按日期实验追踪

status: archived
日期: 2026-08-04

## 目标

把现有行情更新、规则扫描、舆情和多 Agent 研判连接成一个按钮触发的后台批次，并保存规则、AI、混合、基准四组可复现实验结果。后续每次运行先用真实行情回填历史批次的次日开盘买入价和到期收益。

## 范围

- 统一 `grok-4.5` 配置和密钥读取。
- 扩展 `POST /api/pipelines` 为一键全流程唯一入口。
- 新增实验批次、实验决策和涨跌停价数据结构。
- 新增按日期实验查询 API。
- 改造流程页和台账页。

## 非目标

- 不做开机自启、计划任务或系统服务。
- 不接券商，不自动下单。
- 不在本批次自动跑回测或机器学习。
- 不在样本不足时证明策略有效。

## 验收

- 点击一次后无需继续操作页面，四组全部落库才算成功。
- 四组共享同一数据截面和候选池哈希。
- 下一交易日开盘买入；停牌、缺开盘、一字涨停不假设成交。
- 工作台按信号日期查询，未来未到、缺数据和真实 0 收益可区分。
