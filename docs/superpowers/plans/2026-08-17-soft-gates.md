# 九步流程软门控实施计划

**目标：** 业务步骤失败时记录警告并继续执行可独立完成的步骤，不再因局部问题终止整条流程。

**行为边界：** 不伪造数据。校验失败的数据不写入；防前视、哈希和事务校验仍执行，但异常由编排器记录为警告，后续无依赖步骤继续，依赖缺失步骤明确跳过。

## 任务

- [x] 编排器逐步骤隔离异常，输出 `warning` / `skipped` 和警告汇总。
- [x] 舆情、收益回填、智能体不可用时不阻断扫描与可用实验落库。
- [x] 数据覆盖率不足改为质量警告；无完整上下文的股票继续按现有规则排除。
- [x] 智能体逐股隔离无效输入，并允许返回少于配置上限的有效结果。
- [x] 智能体无结果时只保存规则组和基准组；有部分结果时保存实际可用组。
- [x] 历史补齐记录失败日期后继续处理后续日期。
- [x] 更新流程文档并运行 Python、TypeScript 全量测试。

## 验收

- 九步结果始终包含全部步骤；局部失败显示具体警告，不抛出到任务管理器。
- 规则扫描成功时，即使舆情或智能体失败，也能原子保存可用实验组。
- 哈希错误、未来数据和非法股票不会写入数据库。
- 所有警告和排除原因可从任务结果读取。
